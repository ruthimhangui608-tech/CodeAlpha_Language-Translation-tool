# Language Translation Tool

A simple web tool that translates text between languages.

## Features
- Enter text and choose source and target languages
- Translation powered by the MyMemory Translation API
- Copy button to copy the translated text
- Listen button (text-to-speech) to hear the translation

## How to use
1. Open index.html in any browser
2. Type your text
3. Select the From and To languages
4. Tap Translate
